# Expo Router installation contract

Source: [Expo Router manual installation](https://docs.expo.dev/router/installation/)
Collected: 2026-07-16
Published: Unknown

## Focused source notes

- Install `expo-router`, `react-native-safe-area-context`, `react-native-screens`, `expo-linking`, `expo-constants`, and `expo-status-bar` with `npx expo install` so Expo selects SDK-compatible versions.
- Set `package.json` `main` to `expo-router/entry`. A custom entry may run side effects first, but it must import `expo-router/entry` last.
- The initial layout is `src/app/_layout.tsx` (or `app/_layout.tsx`).
- Configure an application deep-link scheme. Typed routes may be enabled under `experiments.typedRoutes` and are generated by Expo CLI.
- Use `babel-preset-expo` only when a custom Babel configuration is necessary; otherwise Expo supports deleting the Babel config.
- In SDK 56+, application code should import navigation APIs through Expo Router rather than directly from external `@react-navigation/*` packages.
