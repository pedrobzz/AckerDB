# Expo SDK 57 reference matrix

Source: [Expo SDK reference](https://docs.expo.dev/versions/latest/)
Collected: 2026-07-16
Published: Unknown

## Focused source notes

The current stable reference identifies this compatibility matrix:

| Component | SDK 57 target |
| --- | --- |
| Expo SDK | 57.0.0 line |
| React Native | 0.86 |
| React | 19.2.3 |
| React Native Web | 0.21.0 |
| React Native TV | 0.86-stable |
| Minimum Node.js | 22.13.x |
| Android | 7+, compile SDK 36, target SDK 36 |
| iOS | 16.4+ |
| Xcode | 26.4+ |

- Each stable Expo SDK targets one React Native version.
- Canary and beta packages are pre-releases and are not the stable baseline.
- Expo recommends `npx expo install` so package versions stay compatible with the selected SDK.
