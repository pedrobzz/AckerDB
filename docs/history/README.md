# Historical documents

Superseded reports and completed implementation plans, kept for the record of
why AckerDB is shaped the way it is.

Nothing here is current. Every document carries a banner naming what replaced
it; the imperative instructions they contain describe an older repository and
must not be followed. For current contracts see
[Releases and protected branches](../releases.md), [MCP exposure](../mcp-exposure.md),
and the [decision records](../adr/).

They live under `docs/history/` rather than beside the live documentation so
that reading `docs/` never requires knowing which of two similar-looking
procedures is the real one.
