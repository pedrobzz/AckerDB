# Security policy

Report repository, CI, release, dependency, or AckerDB security vulnerabilities
privately through GitHub's **Security → Report a vulnerability** form. Do not
open a public Issue for a suspected vulnerability.

Include the affected commit or package version, reproduction steps, impact,
and any suggested mitigation. Please do not access other people's data,
degrade shared services, publish packages, or retain credentials while testing.

GitHub Issues are appropriate for ordinary bugs and feature requests.
